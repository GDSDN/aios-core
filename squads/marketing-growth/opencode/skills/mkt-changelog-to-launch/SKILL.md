# mkt-changelog-to-launch

## Task Definition

- **Responsible**: `marketing-master`
- **Goal**: Turn raw engineering output into a marketing "Moment".

## Execution Workflow

1. **Commit Audit**: Read the recent changelog or `git log`.
2. **Narrative Extraction**: Identify the "Big Win" for the user.
3. **Asset Pack Production**: Write `docs/marketing/OUTPUTS/launch/launch_pack_<timestamp>.md`.
   - **The Narrative**: "Why this matters".
   - **Distribution Drafts**: X Threads, LinkedIn Milestones, and In-App Popups.
4. **Approval**: **Elicit confirmation** of the "Feature Value" (avoid technical jargon).
5. **QA**: Run `*mkt-editorial-review`.

## Post-Conditions

- [ ] Full launch asset pack is saved.
