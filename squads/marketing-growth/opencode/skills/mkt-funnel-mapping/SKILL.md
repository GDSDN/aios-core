1. Read `docs/marketing/CONTEXT.md`, `docs/marketing/ICP.md`, `docs/marketing/OFFERS.md`.
2. Define funnel stages for THIS product (do not assume e-commerce default).
3. For each stage define intent, safe promise, required proof, CTA, and channels.
4. Write `docs/marketing/OUTPUTS/strategy/funnel-mapping.md`.
