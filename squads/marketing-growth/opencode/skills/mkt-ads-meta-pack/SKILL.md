# mkt-ads-meta-pack

## Task Definition

- **Responsible**: `paid-social-meta`
- **Goal**: Generate a creative testing pack for social channels.

## Execution Workflow

1. **Angle Brainstorm**: **Elicit 3 specific "Angles"** from the User (e.g., Fear of Missing Out, Time Savings, Social Status).
2. **Copy Production**: Write `docs/marketing/OUTPUTS/paid/meta/ads_pack_<timestamp>.md`.
   - **Creative Prompts**: Hook-based image/video concepts.
   - **Primary Text**: Using the **Hook-Body-Payoff** structure.
   - **Headlines**: Using **Pattern Interruption**.
3. **Testing Matrix**: Map each ad to a specific segment in `ICP.md`.
4. **Verification**: Run `*mkt-claims-check` to ensure hooks aren't "Clickbait without Proof".

## Post-Conditions

- [ ] Full ads pack is saved.
- [ ] Creative prompts are ready for production.
