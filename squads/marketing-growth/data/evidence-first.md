# Evidence-first rules (marketing-growth)

Non-negotiables

- Do not invent facts, numbers, quotes, customer logos, or competitor claims.
- If you cannot cite it, do not state it as fact. Use one of:
  - "Assumption:" (explicitly marked)
  - "Hypothesis:" (to test)
  - "Unknown:" (needs research)

Allowed evidence sources

- Project artifacts in `docs/marketing/`.
- Direct quotes from provided materials (with file references).
- Deep Research tool outputs (raw + report) saved under `docs/marketing/RESEARCH/`.

Citation format (lightweight)

- Use inline citations as: `[source: docs/marketing/RESEARCH/<run>/report.md]` or `[source: URL]`.

Research loop

1. State what you know (with citations).
2. List unknowns and assumptions.
3. Run targeted research.
4. Update outputs; keep assumptions clearly labeled until verified.
